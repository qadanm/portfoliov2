# Qadan Tools design

The tools center is an operating surface. A dark olive shell and warm cream lettering connect it to Cover Studio; the featured tool is the only primary action. The layout places the tool first on small screens, uses large readable text, and avoids a navigation system built for nonexistent tools.

The Cover Studio renderer is shared by its preview and PNG export. Text regions are direct tap targets. The cover pattern preserves the make eyebrow, centered dominant model name, a small line aligned to the model's right edge, a compact but legible location footer, and shadow/outline treatment. Broad photo-darkening bands are intentionally absent. Flags retain their natural proportions at one consistent display height, with a subtle dark keyline rather than white mats.

The optional second carousel slide uses the current CarSpotter headlamp lockup, asphalt black, chalk white, and lime. The Qadan Travels avatar and handle give the game a visible creator signature. Each card uses a real car detail and a proportional full-car reveal from the same image. The preview can be enlarged; the owner may pick another card. On iOS, the primary export uses the native share sheet for both PNGs, with a ZIP fallback.
